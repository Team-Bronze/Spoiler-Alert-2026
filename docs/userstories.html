User Stories

General User

  • As a general user, I would like to receive notifications through email or in-app notifications so I can be alerted of recalls no matter where I am.
  • As a general user, I would like the app to tell me if an item I am scanning the barcode of has been recalled, so that I can inform the store promptly.
  • As a general user, I would like to view a list of recent recalls on the home page, so I can stay informed even if I miss an alert.
  • As a general user, I would like to be informed of relevant recall news on the app’s homepage.
  • As a general user, I would like to search and filter recalls by food type or brand, so I can quickly find products I use.
  • As a general user, I would like to view recall details, such as the cause, affected regions, and affected people so I can decide whether I need to take action.
  • As a general user, I would like to create an account that saves my preferences, so I don’t need to reselect them every visit.
  • As a general user, I would like to view my inventory of previously purchased items.
  • As a general user, I would like to remove items from my inventory of purchased items.
  • As a general user, I would like to filter include non-food items, like cosmetics or medication, so I have a complete safety overview.
  • As a general user, I would like to be notified if a scanned product is not yet in the database and receive a follow up notification once it’s been researched, so I know whether it’s safe or recalled.

New User

  • As a new user, I would like to sign up for Spoiler Alert, so I can be notified immediately when a food recall affects me.
  • As a new user, I would like to use my facebook or google account to sign up for Spoiler Alert faster.

Free User

  • As a free user, I would like to use my limited barcode scanning to get recall notifications on products I have purchased.
  • As a free user, I would like to be able to manually log purchased items to add to my inventory if I am unable to scan them.

Premium User

  • As a premium user, I would like to choose specific allergens to receive alerts only for recalls involving those ingredients.
  • As a premium user, I would like to scan receipts, so I can save all purchased items to my inventory without scanning each barcode individually.
  • As a premium user I want to have unlimited barcode scanning to get recall notifications on all products I have purchased without worry of running out of scans.

Recall Reviewer

  • As a recall reviewer at Spoiler Alert, I would like to be able to link an unlisted UPC I found to an ongoing recall in the app.
  • As a recall reviewer, I would like to be alerted if our server is unable to find the product being recalled, so I may manually find it.
  • As a recall reviewer, I would like to manually update missing information if the API fails to import all recall data properly.

Admin

  • As an Admin for Spoiler Alert, I would like the ability to upgrade an account to premium.
  • As an Admin for Spoiler Alert, I would like the ability to degrade an account to general user.
  • As an Admin for Spoiler Alert, I would like the ability to delete an account.
  • As an Admin for Spoiler Alert, I would like to create accounts for other employees of Spoiler Alert.
