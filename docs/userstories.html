User Stories

General User

  • As a general user, I would like to receive notifications through email or in-app notifications so I can be alerted of recalls no matter where I am.
  • As a general user, I would like the app to tell me if an item I am scanning the barcode of has been recalled, so that I can inform the store promptly.

New User

  • As a new user, I would like to sign up for Spoiler Alert, so I can be notified immediately when a food recall affects me.
  • As a new user, I would like to use my facebook or google account to sign up for Spoiler Alert faster.
